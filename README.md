# DDoS Attack Detection System

A cybersecurity project developed to detect and analyze Distributed Denial of Service (DDoS) attacks using network traffic monitoring and security analysis techniques.

## Features
- Detects suspicious network traffic
- Monitors abnormal requests and packets
- Identifies possible DDoS attacks
- Generates attack analysis reports
- Improves network security monitoring
- User-friendly interface

## Technologies Used
- Python
- HTML
- CSS
- JavaScript
- Machine Learning
- Network Security Concepts

## How to Run the Project

1. Clone Repository
git clone https://github.com/23SCSE1012097/DDOS-ATTACK-.git

2. Open Project Folder
cd DDOS-ATTACK-

3. Install Required Libraries
pip install -r requirements.txt

4. Run the Project
python app.py

## Project Objective
The main objective of this project is to identify and prevent DDoS attacks by analyzing incoming network traffic and detecting malicious activities in real time.
